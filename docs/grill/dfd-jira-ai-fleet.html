The fleet opens up into two halves: a thin Forge App (triage, panel, reaper, MCP) and the Worker Daemon (poll → claim → execute → report). The Jira board sits in the centre as the single source of truth; workers talk to it directly with a bot token — Forge never proxies worker traffic.

The exact ordering a single worker follows for one ticket, with what it reads from and writes to each store. This is the "every step" view of the Level-1 worker process.

3Ticket state machine (the queue's data model)

Every flow above ultimately drives this machine. Claim is a normal transition, so Jira's own serialisation gives the fleet its concurrency guarantee for free.

4Failure & recovery flows

Every failure path resolves into a Jira write, so the board self-heals and no orphan state lives outside Jira.

Crash mid-task → reaper requeues

Heartbeat stops → lease goes stale (>15 min) → scheduled reaper transitions In Build → Ready for Build, clears Worker/Lease, comments "requeued after lease expiry".

Duplicate claim → CAS + verify

Transition CAS rejects the loser (HTTP 400). Winner re-reads the issue and confirms Fleet Worker is its own ID before starting.

Run over 2h → timeout

Worker kills the harness, comments the log tail, then requeues (or fails once the retry budget of 1 is spent).

Garbage PR → human rejects

Human closes/requests changes and moves the ticket to Ready for Build or Failed with a comment. No auto-merge, no auto-repair loop.

Ticket edited mid-run → snapshot

Live edits never touch the running agent; the PR body carries the claim-time snapshot and the human reconciles at review.

Stale / wrong claim → reset_claim

An MCP caller or the panel fires reset_claim — same requeue transition as the reaper, clearing Worker/Lease so a human or agent can abort.

Security note (from the doc's open decisions): ticket text is untrusted input into agent runs. The design wraps it in hard delimiters with an untrusted-data preamble, sandboxes the run (tool allowlist, filtered env with no tokens, reset workspace), and relies on the human PR review as the real boundary.
